# PowerBI-Analytics-Dashboard

# Project Overview
This project is an end-to-end data analysis and visualization of e-commerce sales. The objective was to transform raw transactional data into a dynamic, interactive Power BI dashboard that tracks revenue generation, product performance, and sales trends. This project demonstrates proficiency in the complete data pipeline: from data generation and cleaning to advanced DAX modeling and visualization.

# Dataset
1.Source: A mock, highly realistic Flipkart sales dataset generated using Google Gemini.

2.Format: CSV file.

3.Domain: E-Commerce / Retail.

# The Tech Stack

1.Power BI Desktop: For data visualization and reporting.

2.Power Query: For ETL (Extract, Transform, Load) processes, data cleaning, and structuring.

3.DAX (Data Analysis Expressions): For creating custom calculated columns and performance measures.

# Data Collection & Import

1.Generated a comprehensive mock dataset of Flipkart transactions via Gemini and exported it as a raw CSV file.

2.Imported the CSV directly into Power BI Desktop.

# Data Cleaning (Power Query)

1.Handled missing values, removed duplicates, and corrected data types across all columns.

2.Standardized text fields (e.g., product categories, customer locations) to ensure accurate grouping.

3.Filtered out anomalies to create a robust foundation for modeling.
